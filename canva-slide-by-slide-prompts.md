# Canva Slide-by-Slide Prompts

Use each prompt separately in Canva. Generate one slide at a time using a consistent 16:9 keynote style.

Global style for every prompt: premium technical keynote, warm white background, deep navy typography, electric blue primary accent, cyan and violet secondary accents, large readable typography, generous whitespace, clean editorial diagrams, no tiny UI cards, no dense paragraphs, no watermark, all visible text in English.

## 1. Title

Create a 16:9 keynote title slide for a presentation called **Building AI-Friendly Software Architecture**. Add the subtitle **Designing systems that humans and AI agents can understand, explore, and change safely**. Use a minimal composition with the title on the left and a sophisticated illustration of a human engineer and an abstract AI agent looking at the same connected software architecture map on the right. Keep the visual calm, premium, and spacious.

## 2. Central question

Create a 16:9 keynote slide titled **Is your software ready to be understood by an AI?**. Use one large question in the center and a visual of an AI agent entering an unfamiliar software system, represented as a maze or complex architecture map. Use very little text and strong negative space.

## 3. New engineer analogy

Create a 16:9 keynote slide titled **Imagine a new engineer joining your team**. Place a new engineer or abstract person in the center with four large connected labels: **Domain**, **Systems**, **Decisions**, and **Operations**. Use a clear radial composition, large labels, and no extra paragraphs.

## 4. Discovery paths

Create a 16:9 keynote diagram slide titled **People need paths to discover knowledge**. Show a large node called **New Engineer** connected to five large nodes: **Repository**, **Documentation**, **Architectural Decisions**, **Dashboards**, and **Incidents**. Use large readable shapes, clean connecting lines, and generous spacing.

## 5. AI onboarding

Use a clean split composition and subtle contrast between the two journeys.

## 6. Common diagnosis
