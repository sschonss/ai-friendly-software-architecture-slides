# Building AI-Friendly Software Architecture Slides

Slidev presentation project for the talk based on the series [Building AI-Friendly Software Architecture](https://luizschons.com/series/arquitetura-ai-friendly).

## Setup

```bash
npm install
npm run dev
```

Then open the local URL printed by Slidev.

## Commands

```bash
npm run dev       # local development server
npm run build     # production web build
npm run export    # export slides to PDF
```

## Project files

- `slides.md`: executable Slidev deck
- `ai-friendly-architecture-presentation.md`: complete content outline, including the extended OpenTelemetry section
- `styles/`: reserved for shared theme styles
- `components/`: reserved for reusable Vue slide components
- `public/`: images, videos, and other static assets
